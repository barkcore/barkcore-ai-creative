# つなぐサービスのメモ（MCP）

Codexにつなぐサービスのチェックリストです。つなげたら [ ] を [x] にしましょう。

- [ ] Gmail … メールを読んだり、返信の下書きを作ってもらえる
  - つないだあとのテスト：最新のメールの件名を3件だけ読む（本文は読まない）
  - 注意：送信は必ず自分で確認してから。最初は「読むだけ」「下書きだけ」にしましょう。
- [ ] Googleカレンダー … 予定を見て、空き時間を探したり、予定を整理してもらえる
  - つないだあとのテスト：今日と明日の予定を読む
  - 注意：予定の追加・変更・削除は、実行する前に必ず確認してもらいましょう。

## 約束
- パスワードやAPIキーはAIに教えない。ログイン画面には、自分で入力する。
- 最初は「読むだけ」で試す。書き込み・送信は、毎回確認してから。
