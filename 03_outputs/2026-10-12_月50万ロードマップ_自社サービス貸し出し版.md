# 月売上50万円ロードマップ（第3版：自社サービスを貸し出す形）

作成日：2026-10-12
状態：試算。数字は仮置きで、約束ではありません。第1版・最短版は残してあります。

## 1. 今回わかったこと（本人回答）
- 自社サービスの候補は2つ。**これを貸し出す（月額）**形にする。
  1. **PDF → OCRで文字認識 → Excel → 在庫管理・請求**（確度が高そう）
  2. **日報 → 請求書**（相手から出た案だが、実際に使うかは未確認）
- ほかのサービスはまだ考えていない。HPは「ギリできる」くらいの位置づけ。
- 営業の入口：ツテがある先は直接 / ほかはメール・フォーム / SNS / 商工会議所・県議会議員などの紹介。
- 見込み先は4社、拓海さん週40時間、ゆづきさん週20時間（前回回答）。

## 2. 前の計画から変わる点
- 最短版は「開発費が入る単発を先に」でした。**貸し出し型は開発費がない（月額のみ）**ので、すぐには売上にならず、積み上げ型です。
- そのぶん、**最短で50万円に届く時期は後ろ倒し**になります。
- 早く現金を作る役目は **HP（10万円＋フォーム1万円の仮案）** に任せます。HPは、入口の仕事とサービスの紹介の両方に使えます。

## 3. 50万円は何社で届くか（月額は未定のため3パターンで試算）
HP売上を除き、**月額だけで50万円**にする場合：

| 月額（税別・仮） | 必要な契約数 |
|---|---|
| 2万円 | 25社 |
| 3万円 | 約17社 |
| 5万円 | 10社 |

現実的には、HPの単発売上と月額を組み合わせます。

| 例 | 内訳 | 月の売上 |
|---|---|---|
| 組み合わせ例A | HP 2件（22万円）＋保守10社（5万円）＋サービス月額 8社×3万円（24万円） | 約51万円 |
| 組み合わせ例B | サービス月額 10社×5万円 | 50万円 |

月額を高くしすぎると導入のハードルが上がり、安くしすぎると社数が必要になります。**まず価格を決める**のが最優先です。

- 「毎月安定して50万円」：**2027年4〜5月ごろ**（約6〜7か月）が現実的な目安。

| 時期 | やること | 月の売上の目標 |

| 〜2026年10月末 | ① 2つのサービスの料金案と範囲を決める ② 動くデモを作る（OCRが先） ③ 4社に連絡 ④ 自社HPを公開 | 0 |
| 2026年11月 | 4社に「HPの提案」と「サービスの試用のお願い」を同時に出す。最初の1〜2社に試用の合意（他社にも提供することを伝えて合意をもらう） | 0〜10万円 |
| 2026年12月〜2027年1月 | 試用（無料〜割引を条件つきで）で改善。HPを2〜3件。紹介・メール・SNSを本格化 | 10〜30万円 |
| 2027年2〜3月 | 試用の会社を有料に切り替え。事例の掲載許可。新規の声かけを継続 | 25〜40万円 |
| 2027年4〜5月 | 有料5〜10社＋HP＋保守 | 50万円 |

## 5. 2つのサービスの進め方（優先順位）
**① PDF→OCR→Excel→在庫管理・請求（先にやる）**
- 会社から要望があり、確度が高い。ナレッジでは「紙・FAX→Excel」まで記録していて、**在庫管理と請求まで広げるのは今回の新しい範囲**。最初から広げず、まず「PDF→Excel」を動かし、在庫・請求は次に足す。
- 先に確認すること：①PDFの種類（FAX、納品書、請求書など）と枚数 ②今のExcelの形 ③例外（手書き、読み取れない文字）④読み取りの費用（OCRの利用料）をどう価格に入れるか。
- 価格案：基本月額＋読み取り枚数の上限、超過は追加（ナレッジの方針）。OCRの実費を計算してから決める。

**② 日報→請求書（確認してから）**
- 試作品はあるが、まだ誰にも見せていない。「実際に使うか分からない」ので、**作り込む前に、出した相手1社に見せて反応を聞く**。
- 反応がよければ、日報の入力→荷主別の集計→請求書の下書きへ進める。本格的な請求書発行までは、まだ完成と言わない。

**時間の見方（ゆづきさん週20時間）**
- 月約80時間。HPの制作・修正と、サービス2つの開発を同時にやるには足りません。
- 目安：OCRに約8〜10時間/週、HPと保守に約5〜7時間/週、日報に約3〜5時間/週。HPの受注が増えたら、日報を後ろにずらす。

## 6. 営業チャネル（拓海さん週40時間の使い方）
| チャネル | 進め方 | AIに任せること |
|---|---|---|
| ツテのある先（4社） | 直接。HPとサービスの試用を同時に提案 | 提案資料、デモ、商談メモ |
| メール・フォーム | 週20〜25件。業種を絞る（OCRなら紙・FAXが多い会社） | リスト、文面の下書き、追いかけ文 |
| SNS | 週数回の投稿（制作の裏側、困りごとの解決例）。実績がないので、事実だけ載せる | 投稿案、画像案 |
| 商工会議所・県議会議員などの紹介 | 紹介してもらう資料を用意。会う前に、紹介先に迷惑のない依頼内容を決める | 紹介用の1枚資料、お礼・フォロー文 |

守ること：
- メール送信・フォーム送信・SNS投稿は、内容を見せて許可をもらってから行う。
- 紹介をお願いする文面は、相手との関係に関わるので、拓海さんが必ず確認する。
- 実績・導入効果・お客さんの声は、まだ事実がないので書かない（ナレッジの方針）。

## 7. AIに任せる範囲（前の版から継続）
- 営業：リスト、文面の下書き、商談メモ、追いかけ、見積もり案
- 提案：デモ、提案書
- 制作：HP、サービスの開発
- 経理：記録、請求書の下書き（発行は人、税務は税理士）
- 問い合わせ：一次返信の下書き

## 8. リスク
- **サービスが使われない**（特に日報）：作る前に見せる。1社でも使ってもらってから広げる。
- **OCRの読み取りミス**：人の確認の画面を入れ、ミスの扱いを契約前に決める。
- **開発費なしで時間だけかかる**：HPで現金を作りながら進める。
- **最初の会社に作り込みすぎる**：他社にも使えるかを先に考える（ナレッジの方針）。
- **ゆづきさんの時間不足**：受注のしすぎに注意。HPは月5〜6件まで。
