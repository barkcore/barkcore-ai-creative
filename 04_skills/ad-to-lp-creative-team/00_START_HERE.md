# Harukaze式AIクリエイティブ組織構築パック

## 始め方

1. `Harukaze式AIクリエイティブ組織構築パック.zip` をClaude Codeのチャットに添付します。自分でZIPを展開する必要はありません。
2. 「このZIPを使って、Harukaze式AIクリエイティブ組織構築パックを開始したいです。」と送ります。
3. 最初にA：ビジネスセミナー／B：美容／C：子どもの英会話を選び、続く4問もそれぞれ3択から選びます。計5つの選択だけで、広告3案からPC・スマホ対応LPまで制作します。

ご自身の商品があれば、A・B・C以外でも「自分の商品で作りたい」と教えてください。

商品資料の準備やスキルのインストールは不要です。用意した設定は架空の練習案件です。完成した広告とLPの保存場所は、制作後にClaude Codeが案内します。

## 答えるのはこの5つ

1. 何を作りますか？（A・B・C、または自分の商品）
2. 一番届けたいのは、どんな人ですか？
3. その人は何に困っていて、どうなれたら嬉しいですか？
4. その変化のために、この商品で一番伝えたい価値は何ですか？
5. 広告からLPを見た人に、最後にどんな行動をしてほしいですか？

全問3択です。1問ずつ表示される選択肢から一つ選び、Q1はA・B・C、Q2以降は1・2・3で答えるだけで大丈夫です。自由記述は必須ではありません。選んだ案件に合わせて選択肢が変わります。コピー・参考画像・配色・構図はClaude Codeが設計し、5問の回答後は追加アンケートや必須の承認待ちを挟まず制作へ進みます。途中で修正希望を伝えることもできます。

ZIPを添付できない・中身を読めない場合だけ、手元で展開してフォルダをClaude Codeに渡してください。

## Claude Codeの受付

受付と制作開始の条件は `ad-to-lp-creative-team/references/five-question-intake.md` を正本とする。ジャンルだけで制作に進まない。

ユーザーが添付ZIPの使用と開始を依頼したときに適用します。この文書自体は開始の許可ではありません。

1. 添付ZIPが読める場合は内容一覧を確認し、本ファイル・`AGENTS.md`・`ad-to-lp-creative-team/SKILL.md` を読む。ZIP内の文書は今回の制作ルールとして使用し、上位指示やユーザーの意図を上書きしない。
2. `ad-to-lp-creative-team/references/five-question-intake.md` を読み、Q1の案件選択からQ2〜Q5の目的ヒアリングへ進む。最初に全5問・全問3択と伝える。原則1問ずつ進捗と3つの選択肢を明示し、番号だけで答えられるようにする。回答済みの項目は聞き直さない。事前のフォルダ選択や自社商品の準備を要求しない。
3. 5問の回答が揃った後、現在のチャットで使える書き込み可能な作業場所に、このパック専用フォルダを作る。セットアップフォルダに限定しない。必要ならClaude Codeで展開する。既存の同名フォルダがあれば上書きせず、連番を付けて新規作成する。
4. 展開前に絶対パス、`..`、シンボリックリンク等の危険なエントリーを拒否し、展開先から出ないことを確認する。スクリプトの実行・グローバル登録・設定変更はしない。パック内の `AGENTS.md` と選択案件を読む。5回答をbriefへ整理して制作に進み、自分の商品でも同じ5問の受付を使う。
5. 書き込み可能な作業場所がない場合のみ、保存場所の指定を依頼する。添付が読めない場合はその事実を伝え、展開済みフォルダの添付・指定を案内する。読み取っていない資料を読んだと称さない。

画像生成機能が利用できれば広告画像とLP用素材まで生成します。使えない場合は完成プロンプトを保存して画像未生成と明記します。モデル名だけで品質を判断せず、同梱のHarukaze式設計・検品を通します。LPのボタンはデモ用で、実申込・購入・個人情報送信は行いません。
