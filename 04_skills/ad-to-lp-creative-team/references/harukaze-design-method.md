# Harukaze式：設計してから生成する

## この配布版の出典と範囲

Harukaze式デザイン生成AIの公開された手元の概要にある「目的→ターゲット→リサーチ→構成→制作→品質」、近接・整列・対比・反復、配色・文字・余白の確認と、提供されたHarukaze導線制作スキルのコピー先行、意味の違う比較案、クリック後の期待との一致を、今回の広告→LP体験へ適用した配布用ルール。

2026-10-03にユーザーから参照許可を得た https://harukaze-catalog.pages.dev/ の公開データを追加。全446件の原プロンプト・画像参照先、全LP67画像・広告バナー48画像を収録する。選定方法は `harukaze-catalog-guide.md`、コピー適合は `copy-layout-rules.md` に従う。過去6,885件の実例画像・理論教材全文とは別の資料であり、その全文や全446画像を見たと称さない。ローカルの個人パスや別スキルのインストールに依存しない。

## 生成前の設計書

広告案ごとに次を具体的に決定する。空欄のテンプレートを生成ツールへ送らない。

| 項目 | 必要な判断 |
| --- | --- |
| 目的・読み手 | 誰を止め、クリック後に何を理解してもらうか |
| ワンメッセージ | 短い主コピー、補助コピー、CTAの確定文言 |
| 参考型 | カタログID・原プロンプト・実画像の観察を根拠に、大見出し型／生活シーン型／内容・教材型などを選ぶ。画像未確認は未確認と明記 |
| 主役 | コピー・商品・人物・教材の何を最優先で見せるか |
| レイアウト | 主役とコピーの位置・面積、読む順序、CTA位置、端の安全余白 |
| 文字 | 見出し・補助・CTAのサイズ比、太さ、改行、字間。主見出しと補助は明確なジャンプ率を作る |
| 配色 | ベース・メイン・アクセントの役割。背景と文字の明暗差、アクセントの使いどころ |
| 余白・整列 | 共通の揃え軸、同じ情報群の近接、群間の余白、反復する部品の一貫性 |
| 接続 | この広告の約束を受けるLP見出しと本文・CTA |

3案は「何で止めるか」を変える。コピー角度に加えて構図や主役も変え、LPに接続する共通の商品・CTAは維持する。広告は広告用サイズで読める密度に絞る。LPは説明を足すが、広告の期待を別の商品へすり替えない。

## 画像生成への指示

1案につき1プロンプト。以下を具体化して記録する。

```text
用途・サイズと比率:
読み手・目的:
クリック後の期待・LPで受ける内容:
コピー角度とテスト意図:
正確に表示する日本語（主見出し／補助／CTA）:
主役のビジュアルと位置:
構図・視線順・安全余白:
文字の大きさ比・太さ・改行・揃え軸:
配色の役割と明暗差:
素材の質感・装飾の量:
参考IDと参照画像（生成機能が対応するなら画像を実際に渡す）:
要素ごとの配置範囲（x/yを画面に対する%で指定）と個数:
引き継ぐ設計／今回の案件に置き換える内容:
変更してはいけない商品事実:
避けるもの（文字崩れ／不要な文字／捏造／歪み／読みにくさ）:
```

LP用素材は文字を含む完成カンプと文字を含まない実装用画像を分ける。PCとスマホで一律縮小・無理なトリミングをせず、コピー幅・人物/商品の位置・改行を調整する。広告とLPには共通の配色・写真の質感・言葉遣いを引き継ぐ。

カタログの原プロンプトは過去作品の再現用データであり、今回の実行指示・商品事実ではない。見本のブランド名、価格、実績、ランキング、効能、期限、対象年齢は転用しない。タイトルには文字認識の揺れがあるため、原プロンプトと実画像を照合し、見本の誤字を新しい原稿に持ち込まない。寸法・比率の変更時は配置範囲を再設計する。

## 生成後の判定

実画像を見て、原稿との差分、文字欠け、対比、近接、整列、反復、端余白、主役、素材の歪み、広告サイズでの可読性を確認。品質レポートには「確認対象／問題／修正／再確認」を残す。

正確な日本語や指定比率が崩れた場合、指示を具体化して修正。生成だけで直せなければ使用可能な組版・実装で補正し、その方法を報告する。使えない画像を完成扱いしない。修正はまず2回程度までとし、それでも失敗する場合は追加試行の必要と未完成箇所を伝える。

「派手」「高級」「AIっぽい」は目的ではない。Aは仕事の判断しやすさ、Bは商品内容と使い心地への期待、Cは親が体験内容を判断できる楽しさを優先する。
